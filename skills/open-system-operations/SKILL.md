---
name: open-system-operations
description: Work on an owned Vibestudio deployment or terminal profile from a user goal.
---

Use `workOnSystemGoal.nl` with the live terminal authority for the current
operator task. The workflow discovers the available targets, reads the selected
hub, and retains the receipts for the actual outcome. It can audit readiness,
start or restart a disposable server, and check or pair a terminal profile.
An authorization hold leaves the target untouched. A completed installer is
followed by an independent hub and child workspace readback.
