# System investigation task bank

`systemInvestigationWorlds` supplies operator goals, observed state, and independent outcome contracts for the System template module. Performance, client, and remote cases carry synthetic observations in the shape the program's documented caller consumes. Local-model and server-log cases carry fixture data for the caller's existing read-only services. The fixture bank deliberately keeps expected findings outside model input.

The verifier requires the exact disposition, ordered diagnostic findings, and the appropriate evidence identifiers. This includes the observed boot identity when the caller's cursor cannot be used. Group IDs bind fixture lineage for future derivatives. No two current rows reuse the same underlying scenario.
